# QuickLook 3.7.3 Custom

A customized version of **QuickLook 3.7.3 Portable**.

Based on the official QuickLook project:

https://github.com/QL-Win/QuickLook

Official QuickLook 3.7.3 Release:

https://github.com/QL-Win/QuickLook/releases?page=2#release-3.7.3

## Changes

* Fixed the issue where the first `Space` press could be ignored after returning to File Explorer with `Alt+Tab`.
* Disabled automatic update checks.
* Removed the **Check for Updates** option from the tray menu.

## How to Use

This version is made for the **QuickLook 3.7.3 Portable** version.

Just download the `QuickLook.exe` from this repository and **replace the original `QuickLook.exe`** in the official Portable package.

No other files need to be replaced.

# QuickLook 3.7.3 Custom

这是基于 **QuickLook 3.7.3 Portable** 修改的版本。

官方项目：

https://github.com/QL-Win/QuickLook

官方 QuickLook 3.7.3：

https://github.com/QL-Win/QuickLook/releases?page=2#release-3.7.3

## 修改内容

* 修复 `Alt+Tab` 返回文件资源管理器后，第一次按 `Space` 可能无法预览的问题。
* 禁用自动检查更新。
* 移除托盘菜单中的 **检查更新**。

## 使用方法

本版本针对 **QuickLook 3.7.3 Portable** 制作。

直接下载本仓库中的 `QuickLook.exe`，然后**覆盖官方 Portable 版本中的原版 `QuickLook.exe`** 即可。

**其他文件不需要替换。**
